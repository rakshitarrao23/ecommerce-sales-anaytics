# 🛒 E-Commerce Sales Analytics

A data analytics project that uses Python, Pandas, SQL, and SQLite to analyze e-commerce sales data and generate meaningful business insights and visual reports.

## 📌 Project Overview

E-Commerce Sales Analytics helps explore sales performance, identify top-selling products, examine payment methods, and understand trends in business data. The project combines data analysis, database queries, and visualizations to support data-driven decision-making.

## 🎯 Objectives

- Analyze e-commerce sales data.
- Identify top-selling products.
- Examine sales across payment methods.
- Generate meaningful business insights.
- Visualize analysis results through charts and reports.

## 🛠️ Technologies Used

- **Python** – Data analysis and processing
- **Pandas** – Data manipulation and analysis
- **SQL** – Querying and analyzing data
- **SQLite** – Database storage
- **Matplotlib** – Data visualization
- **React / Vite** – Frontend interface, where configured
- **Git and GitHub** – Version control and project hosting

## ✨ Key Features

- Sales data analysis
- Product performance analysis
- Payment method analysis
- Database-based data management
- Visual reports and charts
- Organized source code and SQL files

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/rakshitarrao23/ecommerce-sales-analytics.git
```

### 2. Open the Project Folder

```bash
cd ecommerce-sales-analytics
```

### 3. Install Python Dependencies

Install the packages required by the project:

```bash
pip install pandas matplotlib
```

If the project includes a `requirements.txt` file, use the following command instead:

```bash
pip install -r requirements.txt
```

### 4. Run the Sales Analysis

```bash
python src/sales_analysis.py
```

The analysis generates results and saves charts in the `reports` folder, as configured in the project.
